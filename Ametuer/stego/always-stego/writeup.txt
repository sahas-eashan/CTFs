### Core idea

1. Take the **red channel**.
2. Compute how **frequently** each value 0–255 appears.
3. Consider only the **even** indices (0, 2, 4, …, 254).
4. Use the **least significant byte** of each even-bin count as data.

This directly follows the three bold words.

---

### Extraction

```python
from PIL import Image
import numpy as np

img  = Image.open("output.png")
red  = np.array(img)[:, :, 0].flatten()           # red channel
hist = np.bincount(red, minlength=256)           # frequencies

even_bins = hist[::2]                            # 0,2,4,...,254
bs = bytes(int(c) & 0xFF for c in even_bins)     # low 8 bits of each count

print(bs.decode("latin-1"))
```
