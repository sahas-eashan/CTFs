Title: division (AmateursCTF) Writeup

We are given the Sage script:

    flag = int.from_bytes(open('flag.txt','rb').read(),'big')
    x = flag.bit_length()
    r = random.getrandbits(x*3)
    s = random.getrandbits(x*3) >> x*2 << x*2
    p = random_prime(2^(x*3)-1, False, 2^(x*3-1))
    c = (r*flag + s) % p

s is aligned to 2^(2x), so

    r*flag + (2^(2x))*t ≡ c (mod p)

with 0 ≤ flag, t < 2^x.

===== Page 2 =====
We rewrite it as an exact Diophantine equation

    r*flag + M*t – p*k = c,  with M = 2^(2x).

All unknowns are < 2^x (~2^1135).

1. Particular solution:
       t = 0 ⇒ flag0 = c * r^{-1} (mod p)
       k0 = (r*flag0 – c) / p

2. Integer kernel of A = [r  M  –p]:
       ker(A) gives two basis vectors v1, v2.
       Use Sage’s LLL to reduce them (still ~1700-bit entries).

===== Page 3 =====
3. Closest vector (Babai rounding):

       vec0 = (flag0, 0, k0)
       Solve vec = vec0 + a*v1 + b*v2 with each coordinate in [0,2^x).
       Using RealField(4096) to avoid precision loss, compute

           coeff = (G^{-1}) * (-v_i ⋅ vec0)
           a = round(coeff[0]); b = round(coeff[1])

       The rounded coefficients already land us inside the bounds.

4. Verify solution:
       s = t * M
       Check (r*flag + s) % p == c and decode flag.
