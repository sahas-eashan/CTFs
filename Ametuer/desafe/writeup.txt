Challenge: desafe (web)

Overview
- Backend is a tiny Hono server that revives user input with devalue.parse(…, { FlagRequest: … }) and returns flagRequest.flag if the object has admin set.
- FlagRequest constructor deletes its argument instead of storing it, so after parsing the revived instance has no own properties; only its prototype chain matters.
- The challenge text hints that the POST body must be a “devalue stringified” FlagRequest.

Bug
- The deployed devalue version (5.3.0) is vulnerable to prototype pollution (GHSA-vj54-72f3-p5jv / CVE-2025-57820). When parsing a plain object that contains a "__proto__" property, the library doesn’t guard against assigning it directly, so the returned object inherits from whatever the attacker supplies.
- Because revived objects still pass `instanceof FlagRequest`, we can make a POJO whose prototype is the FlagRequest instance generated by the reviver while also setting our own `admin: true`.

Payload construction
1. Build any string that devalue.parse will accept. For FlagRequest instances devalue stores them as `["FlagRequest", <feedback>]`, so we only need the index layout that parse expects.
2. A minimal working serialized array:
   `[{"admin":1,"__proto__":2},true,["FlagRequest",3],[4],"doesnt_matter"]`
   - Entry 0: target object literal with own property `admin` (index 1) and `__proto__` (index 2).
   - Entry 1: the boolean `true` (used for `admin`).
   - Entry 2: definition of the revived FlagRequest instance, referencing entry 3.
   - Entry 3: `["FlagRequest",4]` tells the reviver to instantiate a FlagRequest with index 4 as feedback.
   - Entry 4: actual feedback string (anything).
3. During hydrate:
   - Entry 3 becomes a FlagRequest instance (call it F).
   - Entry 0 is turned into an object whose `admin` points to true and whose `__proto__` points to F. That yields an object with prototype F but its own admin property.
4. Since `.flag` just checks `this.admin`, the getter returns the real flag.

Exploit
```
curl -s -X POST 'https://web-desafe-n7dskaw0.amt.rs' \
     -H 'Content-Type: text/plain' \
     --data '[{"admin":1,"__proto__":2},true,["FlagRequest",3],[4],"test"]'
```
Returns: `amateursCTF{i_love_you_rich_harris}`
